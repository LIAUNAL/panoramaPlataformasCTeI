S4. "mira con los mcp que usamos en smith y morfeo, y en bancos lia, y explora que otras fuentes o mcp podemos utilizar para poder realizar la busqueda de base tecnolgica propuesta" → inventory of MCPs/sources used in papers_smith (papersmith-ai), RedaccionPropuestas (Morfeo) and bancoProyectosPapersLIA, plus other candidate sources/MCPs (patents, articles, platforms, CTeI open data), documented in panoramaPlataformasCTeI/docs/fuentes-y-mcp.md (published) with what was used in the campaign.
S5. Publication decision (user, 2026-11-01): "Repo público, Hēma aparte". Public repo holds only public-source fichas and a public description of Hēma from agenciaatenea.gov.co. The Hēma reference built from meetings/actas (CT000), the gap report and the atenea-portfolio data stay private (informesAtenea / Aracne). coverage_gaps takes the reference ficha from a path outside the public repo.
S6. Constraints: Spanish prose of fichas/docs passes the humanizer style gate (no em dashes, ¿ ¡ opening, score ≤ 0.35); facts only from cited sources, no invented figures; code, identifiers and commits in English, Conventional Commits, no AI attribution; vocabulary in data/vocabulario.json is the closed label set for actores/servicios/interacciones/temas (new terms are proposed, not silently added).
