# Processo de identificação de problemas para fins de inovação

## Descripción
Solicitud brasileña de patente de invención, presentada el 2024-08-12 y publicada el 2026-02-24, que describe un proceso para identificar, analizar y priorizar problemas que vale la pena resolver con innovación. Integra los dominios de mercado, tecnología y requisitos de usuario de forma iterativa e incluye una fase de validación del problema con datos de mercado y opiniones de clientes.

## Actores que atiende
Organizaciones que gestionan innovación y desarrollo de productos. El resumen no restringe el tipo de organización.

## Servicios
- Análisis del contexto con herramientas como DOFA, PESTEL y escenarios.
- Priorización de problemas por relevancia e impacto.
- Validación del problema frente a datos de mercado y retroalimentación de clientes.

## Interacciones entre actores
El proceso se apoya en la retroalimentación de clientes y usuarios para confirmar que un problema merece una iniciativa de innovación.

## Modelo de operación
Titulares: tres personas naturales. La página no muestra el estado de la solicitud.

## Tecnología
No publicada. Clasificación G06Q10/063.

## Ideas para plataformas CTeI como Hēma
- Antes de publicar un reto o una necesidad en la plataforma, pedir al demandante que valide el problema con usuarios o datos de mercado.
- Ofrecer a empresas y pymes una plantilla guiada para formular su necesidad de servicios CTeI.
- Priorizar las demandas recibidas por impacto antes de buscar oferentes.
