# System And Method For An Intellectual Property Marketplace

## Descripción
Solicitud estadounidense sobre un método para transar derechos de propiedad intelectual. Se recibe un documento firmado de cesión a favor de una parte aún indefinida, se reciben ofertas, se determina el ganador y se le entrega el documento.

## Actores que atiende
Titulares de derechos de propiedad intelectual y potenciales adquirentes. La fuente no precisa el tipo de organización.

## Servicios
- Custodia de un documento de cesión firmado por anticipado.
- Sala de datos en línea para la debida diligencia del adquirente.
- Recepción de ofertas y subasta en vivo o electrónica.

## Interacciones entre actores
Cesión de un derecho de propiedad intelectual al ganador de un proceso de ofertas.

## Modelo de operación
Solicitante privado. La página indica estado Abandoned. La prioridad proviene de una solicitud provisional de 2007-03-30.

## Tecnología
No publicada en el resumen.

## Ideas para plataformas CTeI como Hēma
- Ofrecer a las oficinas de transferencia una sala de datos donde el interesado revise la información técnica y legal de una patente antes de negociar.
- Considerar convocatorias de oferta abierta para licenciar resultados públicos, con reglas previas de adjudicación.
