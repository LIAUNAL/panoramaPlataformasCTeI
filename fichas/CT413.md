# Scientific research project application intelligent matching pushing method based on scientific research capability data

## Descripción
Patente china sobre un método que envía a cada investigador las convocatorias de proyectos que mejor se ajustan a su capacidad. El sistema de gestión de investigación de la universidad se conecta con los sistemas de las entidades que supervisan los proyectos y calcula un valor de capacidad por investigador.

## Actores que atiende
Investigadores vinculados a la universidad, la oficina de investigación que administra el sistema y las entidades que abren convocatorias de proyectos.

## Servicios
- Base de datos de investigadores en servicio.
- Modelos de capacidad para ejecutar proyectos, producir resultados y cumplir compromisos.
- Cálculo de un valor de capacidad por investigador.
- Envío de convocatorias acordes con ese valor.

## Interacciones entre actores
Intercambio de datos entre el sistema universitario y los sistemas de las entidades convocantes; postulación del investigador a la convocatoria sugerida.

## Modelo de operación
Solicitante original: Universidad de Ningbo. La página registra la concesión el 2023-04-18 y el estado Active.

## Tecnología
Modelos de valor de capacidad investigadora integrados al sistema de gestión de investigación. No se publica el stack.

## Ideas para plataformas CTeI como Hēma
- Alertar a cada grupo o investigador sobre convocatorias acordes con su trayectoria, como parte del apoyo a quienes se presentan a convocatorias.
- Conectar el directorio de actores con las fuentes de convocatorias de otras entidades para no capturar los datos dos veces.
