# UKRI Gateway to Research

## Descripción
Sitio desarrollado por UKRI para buscar y analizar información sobre la investigación y la innovación que financia. Publica los datos de adjudicaciones cada trimestre y es abierto y gratuito.

## Actores que atiende
Cualquier usuario interesado en la investigación financiada con recursos públicos del Reino Unido, y desarrolladores que integran esos datos en otros sistemas.

## Servicios
- Búsqueda y análisis de proyectos, organizaciones y resultados financiados.
- Dos API (GtR y GtR-2) para extraer la información desde otros sistemas.

## Interacciones entre actores
Terceros enlazan los datos de GtR con otros conjuntos de datos para sus propios análisis.

## Modelo de operación
Servicio público de UKRI, con código abierto, estándares abiertos y Open Government Licence para que terceros reutilicen el código.

## Tecnología
Dos API públicas; la GtR-2 tiene versionamiento y es independiente de la interfaz. Código publicado como abierto bajo Open Government Licence.

## Ideas para plataformas CTeI como Hēma
- Publicar con calendario fijo (por ejemplo trimestral) los datos de las convocatorias y adjudicaciones distritales.
- Ofrecer una API versionada para que observatorios y universidades consuman el directorio sin raspar la web.
