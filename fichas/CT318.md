# DSpace-CRIS

## Descripción
Primera extensión libre y de código abierto de DSpace para la gestión de información y datos de investigación. A diferencia de otros CRIS comerciales, tiene el repositorio institucional como componente central y amplía el modelo de datos de DSpace.

## Actores que atiende
Instituciones con repositorio que quieren gestionar autores, proyectos, financiación y producción, y los investigadores y grupos que aparecen en esos perfiles.

## Servicios
- Modelo de datos flexible para definir entidades, atributos y vínculos (personas, proyectos, premios).
- Gestión de autores con variantes de nombre e identificadores como ORCID.
- Grafo de redes de colaboración.
- Bibliometría y estadísticas agregadas por investigador o por departamento.

## Interacciones entre actores
Sincroniza perfiles, publicaciones y proyectos con ORCID en ambos sentidos y entrega datos a agregadores como OpenAIRE.

## Modelo de operación
Software libre construido y mantenido por 4Science, con documentación en la wiki de LYRASIS.

## Tecnología
Cumple la API v3 de ORCID, Signposting, las directrices OpenAIRE para repositorios, archivos de datos y gestores CRIS (basadas en CERIF), Plan S y los principios FAIR.

## Ideas para plataformas CTeI como Hēma
- Construir el directorio de Hēma sobre un modelo de entidades extensible, con vínculos entre actor, proyecto, servicio y resultado.
- Mostrar el grafo de colaboración entre actores como vista del directorio.
- Adoptar identificadores persistentes (ORCID para personas) desde el inicio.
