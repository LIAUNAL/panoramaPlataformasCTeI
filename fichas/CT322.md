# CERIF: Common European Research Information Format

## Descripción
Modelo de información para el dominio de la investigación científica, pensado para el intercambio de información entre sistemas CRIS. Las directrices de OpenAIRE para gestores CRIS se basan en él.

## Actores que atiende
Desarrolladores y operadores de sistemas CRIS de instituciones y financiadores.

## Servicios
- Modelo de datos documentado con representación RDF.
- Vocabularios semánticos asociados.
- Herramientas para trabajar con el modelo.

## Interacciones entre actores
Dos sistemas que comparten el modelo pueden intercambiar información de personas, organizaciones, proyectos y resultados.

## Modelo de operación
Estándar mantenido por euroCRIS. Un proyecto de refactorización está en curso y un comité técnico define su evolución.

## Tecnología
Repositorios en GitHub (CERIF-DataModel, CERIF-Vocabularies, CERIF-TG-Tools) y RDF bajo w3id.org/cerif.

## Ideas para plataformas CTeI como Hēma
- Alinear el modelo de datos de Hēma con CERIF o con las directrices OpenAIRE para CRIS, de modo que pueda recibir datos de los CRIS de las universidades.
